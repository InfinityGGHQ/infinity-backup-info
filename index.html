Private backup utility

A recovery copy.
A separate place to keep it.

Infinity Market Backups is operated by the owner of Infinity Market to protect the market's database and configuration. It is designed to store encrypted backup archives in the operator's own Google Drive.

This website explains the utility and its data practices. The utility is configured privately by its operator; this website provides no sign-up, Google sign-in, file upload, or backup download service.

Read the privacy policy ↗Contact the operator
01

Verify the backup

A PostgreSQL backup is restored into a separate temporary database to check that it can be recovered. The live database remains in service.

02

Encrypt the archive

The offsite workflow packages the verified backup and encrypts it with age before upload. The operator keeps the recovery key separately from the backup server.

03

Keep a cloud copy

After the operator authorizes Google Drive access, the utility can upload and verify encrypted archives in a dedicated backup folder.

Google Drive access

Permission for the utility's backup files

The utility requests the drive.file OAuth permission and uses it to create, read, verify, and manage its own backup files. The operator grants permission through Google's authorization screen.

Authorization can be revoked through Google Account connections. The privacy policy explains storage, retention, and deletion.
