Infinity Market Backups

Privacy policy

Last updated: 18 November 2026

Purpose and operator

Infinity Market Backups is a private utility operated by the owner of Infinity Market. Its purpose is to create recoverable backups of the operator's market database and configuration and to store encrypted copies in the Google Drive account authorized by the operator. It is intended for the owner and their authorized administration, with no public account registration.

Google data and permissions

The utility requests the Google Drive OAuth scope https://www.googleapis.com/auth/drive.file. It uses this permission to create its backup folder and files and to access the contents and metadata of its own backup files for upload, listing, integrity checks, recovery, and operator-directed management.

File metadata can include names, identifiers, sizes, timestamps, and checksums. The utility's configured workflow does not browse or copy unrelated files in the operator's Google Drive.

Backup contents and encryption

Backup archives can contain database records and private application configuration. Database records may include Discord user identifiers, profile information, sales and payment records, application settings, stored images, audit records, and pending application jobs. Configuration can include application credentials.

The offsite workflow encrypts these archives with age on the operator's server before uploading them to Google Drive. The operator holds the private recovery key separately. Google Drive receives the encrypted archive; descriptive filenames, sizes, and upload times remain visible as file metadata.

Local database backups and temporary files used to prepare an archive are protected by filesystem access controls. Local copies can contain unencrypted data and are accessible to the server operator and authorized system administrators.

Authorization credentials

OAuth credentials used for unattended Google Drive access are stored privately on the operator's server with restricted filesystem permissions. They are used to authenticate backup operations and refresh access when permitted. They are not included in the public website or source repository and are not intentionally published or shared.

Use and sharing

Google user data is used only to perform the backup, integrity verification, recovery, and file-management functions described here. The utility does not sell this data, use it for advertising, or use it to train general-purpose artificial intelligence models.

The server hosting provider and Google Drive provide the infrastructure used by the operator. Google stores uploaded encrypted files under the operator's Google account. The utility does not intentionally make backups public or share them with other Drive users. Access granted separately by the account owner is controlled through that account's sharing settings.

Infinity Market Backups' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The current local backup schedule retains the latest 14 successfully verified copies. Cloud archives are retained until the operator deletes them or a configured retention rule removes them. Cloud retention is controlled by the operator's backup configuration.

The operator can delete cloud archives through Google Drive. Files in Drive's trash remain subject to Google's trash and retention behavior until permanently deleted. Deleting a cloud archive does not delete a separate local copy. Copies downloaded or shared separately by the operator must be managed at their respective locations.

Revoking Google access

The account owner can revoke authorization through Google Account connections and disable the backup schedule on the server. Revocation stops future authorized Drive operations after the revocation takes effect. It does not automatically remove existing cloud archives or local backups.

This informational website

These static pages contain no sign-in form, upload form, analytics script, advertising, or tracking cookies added by the utility. The hosting provider may process ordinary request information, such as IP addresses and browser information, when serving the pages under its own privacy practices.

Questions and updates

Contact the operator through the Infinity Market Backups support page. Public support requests should not include credentials, recovery keys, database records, or backup archives. The operator will update this policy when the utility's data practices change.
